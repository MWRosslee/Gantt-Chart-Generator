# Excel Gantt Add-In (XLAM-ready)

This repository now includes VBA source code for an Excel add-in that builds and tracks a project-management Gantt plan with:

- Tasks, sub-tasks, and sub-sub-tasks (3-level WBS)
- Resource and person allocation
- Multi-project consolidation
- Timeline scales by day/week/month
- Date ranges that can span multiple years
- Basic status reporting and rollups

## Files

- `excel_addin/VBA/modGanttAddIn.bas`
- `excel_addin/VBA/modGanttReporting.bas`
- `excel_addin/VBA/modGanttRibbon.bas`
- `excel_addin/VBA/modUtils.bas`

## Create the XLAM manually

1. Open Excel and create a new blank workbook.
2. Press `ALT+F11` to open the VBA editor.
3. `File -> Import File...` and import each `.bas` file from `excel_addin/VBA/`.
4. Save as `Excel Add-In (*.xlam)`.
5. In Excel, enable the add-in through `File -> Options -> Add-ins -> Go...`.

## Workbook model expected by macros

### Sheet: `Projects`
Columns:
- A `ProjectID`
- B `ProjectName`
- C `Owner`
- D `StartDate`
- E `EndDate`
- F `Status`

### Sheet: `Tasks`
Columns:
- A `ProjectID`
- B `TaskID`
- C `ParentTaskID` (blank for top-level tasks)
- D `WBS`
- E `TaskName`
- F `Level` (1,2,3)
- G `StartDate`
- H `EndDate`
- I `%Complete`
- J `Status`
- K `ResourceGroup`
- L `Person`
- M `EffortHours`
- N `BaselineStart`
- O `BaselineEnd`

### Sheet: `Resources`
Columns:
- A `ResourceGroup`
- B `Person`
- C `CapacityHoursPerWeek`
- D `CostRate`

### Sheet: `Consolidated`
Generated by macro. Contains flattened WBS plus timeline blocks.

### Sheet: `Report`
Generated by macro for KPI summaries.

## Start workflow in Excel

1. Run `InitializeWorkbook`
2. Populate `Projects`, `Tasks`, `Resources`
3. Run `BuildConsolidatedView`
4. Run `RenderGantt`
5. Optionally run `CreateStatusReport`
